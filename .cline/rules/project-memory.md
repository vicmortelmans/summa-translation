# Project memory

This project keeps its durable knowledge in `.cline/memory/`.

Before making non-trivial changes:

1. Read `.cline/memory/README.md` to find the relevant document.
2. Read the relevant memory documents (architecture, decisions, solutions,
   current-state) before modifying related parts of the project.
3. Respect documented architectural decisions and conventions.
4. Keep the documentation in `.cline/memory/` up to date when a session produces
   new durable knowledge (decisions, verified solutions, changed state).
5. Do not load the whole memory repository when only a subset is relevant.
